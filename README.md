# Facilit-Solu-es-Financeiras-Sistema-de-Gest-o-Financeira
Projeto privado / desenvolvido sob demanda Sistema web para gerenciamento de clientes, contratos, parcelas e cobranças, com automações de cobrança, integração com Pix/Mercado Pago, WhatsApp e geração de comprovantes. Tecnologias: Python, FastAPI, React, TypeScript, MySQL, Docker e APIs REST.
